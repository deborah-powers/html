== Les fonctions

** Forme basique

Code
function doSomething (parametre1, parametre2){
	// déclaration
	var res = true;
	if (parametre2 === undefined) parametre2 = 21;	// appliquer un paramètre par défaut sans es6
	// do something;
	return res;	// renvoyer une valeur à l'appelant. facultatif pour la fonction
}
doSomething ('coucou', 45);	// appel
/
Paramètre: Variables utilisée dans une fonction, attendues lors de l'appel. Parametre2. Si sa valeur n'est pas précisée, elle vaut undefined par défaut.
Argument: Valeurs transmises à une fonction lors de son appel. 45
return vaut undefined par défaut. Si on éssaie de récupérer un résultat d'une fonction qui ne renvoi rien.
Cette fonction peut être appelée au-dessus de sa déclaration.
Es6 peut utiliser des paramètres par défaut
Code
function doSomething (parametre1, parametre2='hello'){	// appliquer un paramètre par défaut avec es6
	if (parametre1 === undefined) parametre1 = 21;	// appliquer un paramètre par défaut sans es6
}
/

** Fonction en expression

Code
const doSomething = function (parametre1, parametre2){
	// do something;
	return res;
};
doSomething ('coucou', 45);
/
On considère que la fonction est anonyme. Cette fonction ne peut pas être appelée au-dessus de sa déclaration, même si on utilise var ou let.

** Fonction flèchée

Que depuis es6.
Code
const doSomething = (parametre1, parametre2) => {...};
const functionOneParam = paramUnique => {...};	// si 0 ou plusieurs paramètres, besoin des parenthèses
const functionSingleLine = (parametre1, parametre2) => parametre1 + parametre2;	// le résulultat sera toujours renvoyé
